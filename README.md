# An-lise-de-Carteira-e-Negocia-o-de-Dividas-com-SQL
Projeto desenvolvido em SQL com uma base fictícia de clientes, contratos, dívidas e negociações. Foram realizadas análises de carteira, inadimplência, risco, parcelas, canais de atendimento e desempenho operacional. Utilizei CASE, funções de agregação, RANK, CTE, VIEW e painel de indicadores.
